# Remote Sync: Jakarta - Berlin

A simple, beautiful time zone synchronization tool for remote teams working between Jakarta (WIB) and Berlin (CET/CEST).

## Features

- **Real-time Clock Display**: Shows current time in both Jakarta and Berlin
- **Work Status Indicator**: Visual indicators for work hours, personal time, and sleep hours
- **DST Awareness**: Automatically handles Germany's Daylight Saving Time transitions
- **Meeting Planner**: Interactive slider to find the best meeting times across time zones
- **Modern UI**: Glassmorphism design with smooth animations

## Usage

Simply open `index.html` in your browser. No build process or dependencies required.

## Time Zones

- **Jakarta**: UTC+7 (WIB) - constant throughout the year
- **Berlin**: UTC+1 (CET) in winter, UTC+2 (CEST) in summer

The time difference varies between 5-6 hours depending on DST.
